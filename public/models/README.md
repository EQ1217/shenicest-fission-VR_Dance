# 场景模型说明

本目录下的 `.glb` 文件均为 Poly Pizza 免费低模模型，许可为 **CC0（Public Domain）**，可免费使用、无需署名。

| 文件 | 名称 | 来源 |
| --- | --- | --- |
| pine_trees.glb | Pine Trees | https://poly.pizza/m/oYtDty0fR6 |
| birch_trees.glb | Birch Trees | https://poly.pizza/m/R7qMWzb7nk |
| fern.glb | Fern | https://poly.pizza/m/jqcanvH7D6 |
| flowers.glb | Flowers | https://poly.pizza/m/NBUxHir6FJ |
| log_moss.glb | Wood Log with Moss | https://poly.pizza/m/nwsYvcI0bC |
| rock_large.glb | Rock Large | https://poly.pizza/m/54jZKTAt5p |
| rocks.glb | Rocks | https://poly.pizza/m/OQvi8PIZ40 |
| crystal_a.glb | Crystal | https://poly.pizza/m/dxCmHfpqc5 |
| crystal_b.glb | Crystal | https://poly.pizza/m/WzWPKHFMkL |
| mineral.glb | Mineral | https://poly.pizza/m/STixpWYaTd |

用途：`src/mr.js` 会按场景把这些模型布置在「焦点舞台布景」和「环绕观众 360° 环境」中；加载失败时自动降级为程序化几何体，不影响演示。
